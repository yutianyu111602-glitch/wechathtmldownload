重要发现

  • 全量 LLM 产物是宽泛文章图谱，不是 DJ-first 历史关系网。
  • 旧 UI 的 OIL 档案是 exact-name full，不是 canonical full。
  • 修复后 OIL 合并 OIL油 / OIL Club / OIL CLUB / 深圳OIL 等别名，达到 17,848 实体行、9,924 来源文章、60,573 活动。
  • 源 URL 已在私有 sidecar 层恢复到 138,102 / 138,102，但不能公开暴露。
  • SHCR、BYYB、baihui、CDCR 是电台/媒体平台，不应作为噪音删掉。

坑点

  • 不能把 150 万实体和 60 万活动直接塞进浏览器。
  • 不能把同文章共现当强 DJ 关系；强关系必须优先来自同活动/同厂牌/多次同台。
  • 不能公开 raw source_url、raw HTML path、source DB path、bulk export。
  • 不能继续盲目花钱跑 full LLM；先吃掉 deterministic repair sidecar。
  • 不能把 Boiler Room 这种 substring 命中卷进 OIL profile。
  • 不能把 深圳 这种 city-only place 当场地节点。

下一步

  1. 构建 report-only atlas_serving.sqlite materializer。
  2. 物化 canonical_dj、performance_event、dj_event_edge、dj_dj_relation_rollup、search_document、graph_window_cache。
  3. 先接受 auto_candidate，review_candidate 留在私有审核台。
  4. 用 atlas:graph:selftest 和真实 DJ/场地样本验搜索、profile、graph-window。
  5. 通过反爬/暗数据库 gate 后再部署 atlas.huaidj.club。
