Understand-Anything 和 CodeGraph 怎么配

Understand-Anything 先用

它负责看“大图”：项目分几条线、当前事实入口在哪、哪些文档是 SSOT、哪些文件属于 Atlas/weekly/小程序。

  • 744 files
  • 5569 nodes
  • 4825 edges
  • 适合 docs、配置、WXML/WXSS、JSON、线程边界。

CodeGraph 后用

它负责查“代码调用”：函数在哪、谁调它、它调谁、改它会影响哪些 JS/Python。

  • 431 JS/Python files
  • 10465 nodes
  • 24031 edges
  • getAtlasEvent 的 direct caller 是 createServer。

实际用法

  1. 先读 docs/threads/THREADS_INDEX_20260522.md 和 docs/current-runtime.md。
  2. 用 Understand-Anything 确认 Atlas + 小程序的文件范围。
  3. 只把 JS/Python 子集放进 .understand-anything/codegraph-atlas-miniapp-workspace 给 CodeGraph 索引。
  4. 改代码前用 CodeGraph 查 query、callers、callees、impact。
  5. 写结论时回到 SSOT，分开写本地、上传、审核、远端生效、正式可见。

下一步最安全的事

  1. Cod.Act 继续 blocked，直到有精确 Atlas source context 或 canonical id。
  2. YYYY product-truth mutation 继续 blocked，直到补齐 canonical target id。
  3. 小程序继续把开发版、微信审核、正式用户可见分开记录。
  4. Atlas public serving 只有在 smoke、session/identity、pointer/readback 都清楚后再推进。
  5. 任何 deploy、审核、生产写入前，都先写 gate packet，并保留 rollback/readback 证据。
